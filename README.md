# 陳思朗 Sunny Chan — 個人網站

靜態單頁個人網站。純 HTML + CSS，無 build step、無依賴。

## 本機預覽
```
cd ~/Projects/sunny-site && python3 -m http.server 8755
```
開 http://127.0.0.1:8755

## 結構
- `index.html` — 單頁（關於／工作／項目／點心·牛奶妹／聯絡）
- `assets/site.css` — 全站樣式（紫曜 Violet Aurora 設計語言）
- `shots/` — 預覽截圖（`preview-both.png` = 桌面＋手機對照）

## 內容原則
所有文字一律用一般性描述（車輛認證／流程工程／AI 自動化），**不含**公司名、
客戶名、內部項目代號或任何基建資訊。改動前請保持呢個原則。
